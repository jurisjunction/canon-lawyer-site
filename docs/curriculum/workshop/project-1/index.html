Project 1 · Weeks 4–9

The gates

From one chip, NAND, you build every other kind of gate: fifteen chips in all. Every chip the computer will ever have is made of this one.

Beside Unit 2 · Number and Unit 3 · Nature

In the course: Project 1, Boolean Logic · slides and project notes at nand2tetris.org

The kind of answer

Computed. A gate is arithmetic on true and false, and its truth table is worked out, not guessed. Morse already counts in twos. When you run a chip’s test, the comparison is found, as in Unit 3: it is a fact you look at, and it does not care what you hoped.

On paper first

NAND’s truth table: two inputs, four rows, and the output is 0 only when both inputs are 1. Then, still on paper, find how to make Not with one NAND, and And with two.

Each one is done when its test passes in the IDE. A pass cannot be argued with, and neither can a fail.

Week by week

About an afternoon a week. If a week runs long, let it: the strand keeps its own order, not the calendar’s.

WeekWatchDo
Week 41.1; 1.2The truth tables of Not, And and Or, on paper. Then the trick from lecture 1.2: any truth table can be written as an Or of Ands.
Week 51.3; 1.4How a chip is described in HDL. Write Not, And and Or in HDL on paper, before you touch the computer.
Week 61.5The Hardware Simulator. Type in Not, And and Or, and run each one’s test until it passes. Then Xor.
Week 71.6; 1.7Mux and DMux, on paper first: a Mux is a switch that chooses which input to pass on. Mux is the first real wall; take the week.
Week 8—Buses, sixteen wires at once: Not16, And16, Or16 and Mux16. Then Or8Way.
Week 91.8Mux4Way16, Mux8Way16, DMux4Way and DMux8Way: chips built out of the chips you just made. Then the gates are finished, every one passing its test.

For the parent

HDL describes wiring; it is not a list of steps, so the order of its lines does not matter, and every wire between parts must have a name. Bit 0 of a bus is the rightmost bit, which trips everyone once. When a chip will not pass, go back to its truth table on paper before touching the code. Project 1 is the longest project in Part I, so it walks beside two units.
